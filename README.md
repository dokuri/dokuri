🐍 Contribution Snake
<p align="center"> <picture> <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/dokuri/dokuri/output/github-snake-dark.svg" /> <source media="(prefers-color-scheme: light)" srcset="https://raw.githubusercontent.com/dokuri/dokuri/output/github-snake.svg" /> <img alt="snake animation" src="https://raw.githubusercontent.com/dokuri/dokuri/output/github-snake.svg" /> </picture> </p> <details> <summary>⚙️ <b>Snake setup (click to expand)</b></summary> <br/>

Save this as .github/workflows/snake.yml in your profile repo, then run it once from the Actions tab. Until it runs, the snake image stays blank.

yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 0 * * *"   # runs daily
  workflow_dispatch:       # allows manual run
  push:
    branches: [main]

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
</details>
